## 2. Web-Use Scraping Engine (Playwright Architecture)

### 2.1 Design Objectives
The `web-use` engine collects critical unstructured context from modern Single Page Applications (SPAs) and adversarial platforms that do not provide reliable or public JSON APIs.

### 2.2 Target Surfaces & Handlers
1. **Dynamic DEX Portals (Dexscreener, Photon, BullX, Meteora):**
   - Headless Playwright context with stealth plugins (`playwright-stealth`).
   - Extracts real-time liquidity distributions, pair creation timestamps, and active LP locks.
2. **Social Media & Community Threads (X / Twitter, Telegram Web):**
   - Parses DOM reply threads, quote tweets, and engager timestamps.
   - Extracts posted media URLs for perceptual image hashing (pHash) analysis.
3. **Meme Image & Metadata Harvesting:**
   - Downloads small-variant thumbnails directly to memory buffers for perceptual hashing and Fal.ai visual inspection.

### 2.3 Rate Limiting, Stealth & Isolation
- **Concurrency:** Bounded by an `asyncio.Semaphore(settings.browser.max_pages)`.
- **Resource Abort Policy:** Automatically blocks video, raw fonts, and heavy stylesheet assets (`image`, `media`, `font`) unless explicitly performing media scraping.
- **Degradation Contract:** A browser navigation timeout or captcha challenge sets `degraded=True` on the collector result without crashing the sweep loop.

## 3. Fal.ai Multimodal Media Generation Architecture

### 3.1 Integration & Credentials
- Uses the official `fal-client` Python SDK.
- API Key: Read dynamically from `os.environ["FAL_KEY"]`. If absent, gracefully falls back to local SVG/Pillow rendering.

### 3.2 Visual Asset Pipelines
1. **High-Resolution Social Summary Cards (1200x675 PNG):**
   - Composition:
     - Left pane: Token branding, composite score speedometer, safety veto badges.
     - Right pane: 6-family SVG radar polygon (`onchain_topology`, `social_authenticity`, `community_production`, `narrative`, `team_credibility`, `execution_quality`).
     - Bottom bar: Mandatory disclosure watermark and observation timestamp.
2. **Meme Lineage & Originality Classification:**
   - Queries Fal.ai vision models (e.g. `fal-ai/flux-general` or multimodal vision endpoints) with token imagery to extract visual tags, semantic style, and detect prompt templates.
   - Computes structural similarity against known promotional template banks.

## 4. Detailed Specification of the 20 Improvements

### Phase 6: Live Visual Interfaces & Real-Time Exploration

#### P6-01: Real-Time Live Web Dashboard (`botsensai ui`)
- **Backend:** `src/botsensai/dashboard/server.py` using FastAPI and `asyncio.Queue` event broadcasting.
- **Frontend:** Glassmorphic UI with auto-reconnecting WebSocket client.
- **Key Views:**
  - **Live Mint Firehose:** Streaming pump.fun discoveries with latency metrics.
  - **Candidate Leaderboard:** Live-updating scores, coverage %, and safety veto status.
  - **Integrity Sentinel:** Visual gauges for collector health, rate limit budgets, and database sizes.

#### P6-02: Interactive On-Chain Topology & Funder Graph Explorer
- **Module:** `src/botsensai/dashboard/graph.py`.
- **Visualization:** D3.js force-directed graph.
- **Features:**
  - Nodes: Wallets (Deployer, Snipers, Insiders, Liquidity Pools).
  - Edges: SOL transfers, token purchases, bundle transaction groupings.
  - Color Encoding: Red (Insider/Rug link), Blue (Independent organic buyer), Gold (Liquidity Pool/Bonding curve).

#### P6-03: Full-Featured Terminal TUI (`botsensai tui`)
- **Module:** `src/botsensai/tui.py` built with Textual.
- **Layout:**
  - Top Bar: Market regime (Hot/Normal/Dead), 24h graduation rate, open paper risk.
  - Left Pane: Real-time discovery log.
  - Center Pane: Active candidates & paper orders with live PnL.
  - Right Pane: 34-metric breakdown for selected token with arrow key navigation.

#### P6-04: Visual Token Comparison & Post-Mortem Autopsy Studio
- **Module:** `src/botsensai/autopsy.py`.
- **Commands:**
  - `botsensai compare <mint1> <mint2>`: Differential metric breakdown.
  - `botsensai autopsy <mint>`: Chronological timeline of rugged/graduated tokens.

#### P6-05: Visual Meme Lineage & Perceptual Hash Gallery
- **Module:** `src/botsensai/media/gallery.py`.
- **Features:** Harvests images via Playwright, computes pHash hamming distances, renders visual cluster trees, and applies Fal.ai vision classification.

## 5. Testing & Verification Standard

Every implemented module must have dedicated unit tests under `tests/` asserting:
1. **Determinism:** Given fixed inputs and seeds, outputs must be identical.
2. **Point-in-Time Invariant:** No look-ahead leaks past `as_of` or `observed_at`.
3. **No-Signing Enforcement:** Repository remains strictly non-signing and safe.
4. **Complexity Floor:** `python scripts/backpressure.py` maintains cyclomatic complexity $\le 10$.
